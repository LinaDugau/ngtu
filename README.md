# 📅 Календарь ДТ-660 (PWA)

Учебный календарь группы **ДТ-660** (заочное отделение НГТУ) в виде прогрессивного веб-приложения (PWA). Работает на телефоне и ПК, устанавливается как обычное приложение и полностью работает **офлайн**.

## Возможности

- 🗓 Календарь занятий и событий (данные DiSpace)
- 📝 Конспекты установочных лекций прямо в карточках событий
- ⚠️ Список дедлайнов (контрольные, РГЗ, курсовые)
- 📚 Раздел «Полезное» — материалы, разбитые по предметам
- 📲 Установка как приложение: Android, iOS, Windows/macOS (Chrome/Edge)
- ✈️ Офлайн-режим благодаря Service Worker

## Структура проекта

```
index.html              — точка входа приложения
styles.css              — стили (адаптив, тёмная тема, safe-area для телефонов)
script.js               — данные расписания, конспекты, раздел «Полезное», рендеринг
app.js                  — регистрация SW, кнопка «Установить», офлайн-баннер
sw.js                   — service worker (кэширование для офлайна)
manifest.webmanifest    — манифест PWA (иконки, название, standalone-режим)
schedule.json           — исходные данные расписания (из выгрузки DiSpace)
icons/                  — иконки приложения (SVG + PNG 192/512, maskable)
assets/useful/matan/    — картинки раздела «Полезное» (пока заглушки по матанализу)
```

## Запуск локально

Service Worker и установка приложения требуют HTTPS или localhost:

```bash
# любой статический сервер, например:
npx serve .
# или
python3 -m http.server 8080
```

Откройте http://localhost:8080

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите файлы этого проекта в ветку `main`:
   ```bash
   git init
   git add .
   git commit -m "Календарь ДТ-660: PWA"
   git remote add origin https://github.com/<ваш-логин>/<имя-репозитория>.git
   git push -u origin main
   ```
2. На GitHub: **Settings → Pages → Source: Deploy from a branch → main / (root)** → Save.
3. Через пару минут сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

> Все пути в проекте относительные (`./`), поэтому приложение корректно работает и в подпапке (`/имя-репозитория/`), и в домене `github.io`, и с других статических хостингов (Netlify, Vercel).

## Установка как приложения

- **Android (Chrome):** открыть сайт → кнопка «⬇️ Установить» в шапке (или меню ⋮ → «Установить приложение») → иконка появится на рабочем столе.
- **iPhone (Safari):** Поделиться → «На экран "Домашний"».
- **ПК (Chrome/Edge):** иконка установки в адресной строке или кнопка «Установить» — приложение откроется в отдельном окне.

## Как добавлять материалы в раздел «Полезное»

1. Положите картинку в `assets/useful/<предмет>/` (например, `assets/useful/matan/`).
2. Добавьте запись в массив `usefulData` в `script.js`:
   ```js
   { src: 'assets/useful/matan/nazvanie.png', alt: 'Описание' }
   ```
3. Пропишите новый файл в список `CORE_ASSETS` в `sw.js` и поднимите версию кэша (`dt660-calendar-v3`), чтобы офлайн-копия обновилась.

## Примечание

Файлы `extract-all.js` и `parse-har.js` — локальные утилиты для разбора HAR-выгрузки DiSpace, в репозиторий не включены (см. `.gitignore`).
