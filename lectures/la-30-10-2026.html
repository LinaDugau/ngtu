3. Что преподаватель особенно выделил

  • Минор и алгебраическое дополнение — не одно и то же. Знак зависит от чётности суммы номера строки и столбца.
  • При разложении определителя удобно выбирать строку, содержащую переменные x, y, z.
  • В уравнении плоскости коэффициенты при x, y, z — координаты её нормального вектора.
  • В каноническом уравнении прямой знаменатели — координаты направляющего вектора.
  • Для высоты пирамиды направляющим вектором служит нормальный вектор плоскости основания.
  • Для нахождения точки пересечения удобнее перейти к параметрическому уравнению прямой.

4. Формулы, которые нужно знать

4.1. Определители — повторение

Определитель второго порядка:

|a b; c d| = ad − bc

Алгебраическое дополнение элемента:

Aij = (−1)i+j Mij

Разложение определителя по строке i:

det A = Σ aij Aij

4.2. Общее уравнение плоскости

ОСНОВНАЯ ФОРМУЛА ЗАНЯТИЯ

Ax + By + Cz + D = 0

Нормальный вектор плоскости:

n = (A, B, C)

Уравнение плоскости через точку M₀(x₀, y₀, z₀) с нормальным вектором n = (A, B, C):

A(x − x₀) + B(y − y₀) + C(z − z₀) = 0

4.3. Уравнение плоскости по трём точкам

Преподаватель попросил обратить особое внимание на эту формулу!

x−x₁y−y₁z−z₁
x₂−x₁y₂−y₁z₂−z₁
x₃−x₁y₃−y₁z₃−z₁
= 0

Нюанс: в первой строке остаются переменные x, y, z, во второй и третьей — конкретные числа. Поэтому определитель раскрывают по первой строке.

4.4. Уравнение плоскости в отрезках

x a + y b + z c = 1

Где a, b, c — ненулевые координаты точек пересечения плоскости с соответствующими осями.

4.5. Каноническое уравнение прямой

x − x₀ p = y − y₀ q = z − z₀ r

Где:

  • M₀(x₀, y₀, z₀) — точка на прямой
  • m = (p, q, r) — направляющий вектор прямой

4.6. Параметрическое уравнение прямой

НЕОБХОДИМО ДЛЯ ПОИСКА ТОЧКИ ПЕРЕСЕЧЕНИЯ

x = x₀ + pt
y = y₀ + qt
z = z₀ + rt

Самое важное: для поиска точки пересечения прямой с плоскостью нужно подставить эти выражения в уравнение плоскости, найти t, затем вычислить координаты точки.

5. Разбор задания № 3

Внимание! Преподаватель использовал демонстрационный вариант для шифра `03` (n=3, m=10). В своей контрольной используйте собственные значения n и m!

Даны вершины пирамиды:

A(5, 1, 1), B(1, 5, 1), C(1, 1, 5), D(0, 0, 0)

Нужно найти уравнение плоскости ABC, уравнение высоты из D и точку пересечения высоты с основанием.

а) Уравнение плоскости ABC

Подставляем координаты в определитель:

x−5y−1z−1
−440
−404
= 0

Раскрываем по первой строке:

16(x − 5) + 16(y − 1) + 16(z − 1) = 0

Сокращаем на 16:

x + y + z − 7 = 0

Нормальный вектор плоскости:

n = (1, 1, 1)

б) Уравнение высоты из вершины D

Высота перпендикулярна плоскости ABC. Поэтому её направляющий вектор совпадает с нормальным вектором плоскости.

Прямая проходит через D(0, 0, 0):

x − 0 1 = y − 0 1 = z − 0 1

Получаем:

x = y = z

в) Точка пересечения высоты с основанием

Переходим к параметрическому виду:

x = t
y = t
z = t

Подставляем в уравнение плоскости:

t + t + t − 7 = 0
3t = 7,    t = 7 3

Итог:

H( 7 3 , 7 3 , 7 3 )
