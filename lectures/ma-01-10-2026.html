2. Что преподаватель особо выделила

  • Необходимо понимать разницу между значением функции и её пределом. Функция может никогда не принимать определённое значение, но стремиться к нему.
  • Бесконечность — не обычное действительное число. При вычислении пределов важно понимать, как изменяются выражения при стремлении аргумента к бесконечности.
  • Неопределённости нельзя считать обычными арифметическими действиями. Например, ∞/∞ и 0/0 требуют преобразования.
  • Многочлен при стремлении аргумента к бесконечности эквивалентен своему старшему члену. Это основной приём для нахождения пределов отношений многочленов.
  • Эквивалентные последовательности можно заменять друг на друга в отношениях при вычислении пределов.
  • Второй замечательный предел нужно знать обязательно. Преподаватель несколько раз повторила его значение и показала применение.
  • Доказательства сложных теорем учить не требуется. Они приведены в курсе для желающих разобраться глубже.
  • Нужно уметь решать простые задачи, а не только запоминать определения.
Преподаватель отдельно отметила, что требования к уровню математического анализа умеренные: главное — освоить основные формулы и научиться правильно применять их на практике.

3. Формулы, которые необходимо знать

Предел последовательности

Последовательность an сходится к числу A, если:

limn→∞ an = A

Формальное определение:

∀ε > 0 ∃N ∀n > N: |an − A| < ε

То есть начиная с некоторого номера все элементы последовательности находятся сколь угодно близко к числу A.

Пример:
limn→∞ 1n = 0
Нюанс: для любого натурального n дробь 1/n не равна нулю, но её предел равен нулю.

Бесконечно малые и бесконечно большие величины

Основные соотношения, которые преподаватель просила запомнить:

1∞ → 0
10 → ∞

Это условные обозначения поведения величин в пределах, а не обычное деление на ноль.

Более строго:

an → +∞ ⇒ 1an → 0

Если an → 0 и an ≠ 0, то 1/an неограниченно возрастает по модулю; знак зависит от того, с какой стороны an приближается к нулю.

Важно: преподаватель использовала запись 1/0 как условное обозначение. В обычной арифметике деление на ноль запрещено.

Неопределённости

Преподаватель выделила три формы:

∞∞      00      1∞

Их нельзя сразу считать равными конкретному числу. Сначала необходимо преобразовать выражение.

Эквивалентные последовательности

Две последовательности эквивалентны, если:

limn→∞ anbn = 1

Обозначение: an ~ bn

Главное правило: многочлен при n → ∞ эквивалентен своему старшему члену.
a0nk + a1nk−1 + … + ak ~ a0nk
Например:
n² + n + 1000 ~ n²
n³ + n² + 1 ~ n³

Поэтому при вычислении пределов отношений многочленов можно переходить к старшим членам.

Второй замечательный предел

ОСНОВНАЯ ФОРМУЛА
limn→∞ (1 + 1n)n = e
e ≈ 2,71828

Вторая форма, которую преподаватель просила освоить:

limα→0 (1 + α)1/α = e

Для последовательности αn → 0 аналогично:

limn→∞ (1 + αn)1/αn = e
Нюанс: чтобы применить формулу, показатель степени нужно привести к виду 1/αn. Если в показателе остаётся коэффициент, он становится степенью числа e.

Пределы функций

Определение предела функции:

limx→x₀ f(x) = A

Условие непрерывности функции в точке:

limx→x₀ f(x) = f(x₀)
На этом собрании преподаватель подробно разбирала именно пределы и последовательности. Непрерывность входит в название модуля, но её подробный разбор в записи ещё не проводился.

4. Примеры, разобранные преподавателем

Пример № 1. Предел отношения многочленов

limn→∞ n² + 1n² + n + 1000

Оставляем старшие члены:

= limn→∞ n²n² = 1

Преподаватель показала два способа: вынесение n² за скобки и замену многочленов эквивалентными старшими членами.

Пример № 2. Предел с разными степенями

limn→∞ n³ + n² + 1n² + 1

Переходим к старшим членам:

= limn→∞ n³n² = limn→∞ n = +∞
Нюанс по вводу ответа: преподаватель сказала, что в системе бесконечность можно обозначать русской буквой б. Если знак бесконечности в задаче существенен, его нужно учитывать.

Пример № 3. Раскрытие скобок перед вычислением предела

limn→∞ (n + 1)³ − n³2n²

Раскрываем куб суммы:

= limn→∞ n³ + 3n² + 3n + 1 − n³2n²

Сокращаем n³, оставляем старшие члены:

= limn→∞ 3n²2n² = 32

Преподаватель привела этот пример как тип задания, которое необходимо научиться решать за неделю.

Пример № 4. Второй замечательный предел

limn→∞ (1 + 13n)n

Приводим показатель степени к нужному виду:

= limn→∞ [(1 + 13n)3n]1/3

По второму замечательному пределу:

= e1/3

Пример № 5. Второй замечательный предел с отрицательным слагаемым

limn→∞ (1 − 1n²)3n²/4

Пусть αn = −1/n². Тогда:

3n²4 = −34αn

Получаем:

= limn→∞ [(1 + αn)1/αn]−3/4 = e−3/4
