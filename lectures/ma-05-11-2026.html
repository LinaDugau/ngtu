Тема: Производные высших порядков, дифференциалы, формулы Тейлора и Маклорена.

Что важно из слов преподавателя

  • Контрольная №2: преподаватель рекомендовала постепенно начинать её выполнять. На следующем занятии планируется применение производной к исследованию функций, после чего контрольную можно будет сдавать.
  • Оформление решений: нельзя просто записывать переходы между формулами без объяснений. Нужно показывать, почему применяется правило или преобразование.
  • Типичные ошибки: потерянные степени, логарифмы, штрихи производных, скобки и знаки.
  • Нейросети: преподаватель отдельно предупредила, что бездумно переписанные решения с ошибками оцениваются очень низко.
  • Нюанс: при дифференцировании неявной функции обязательно учитывать, что y зависит от x, поэтому появляется множитель y'.

Основные формулы занятия

1. Производные высших порядков

Вторая производная — производная от первой:

f''(x) = (f'(x))'

Производная n-го порядка:

f(n)(x) = (f(n−1)(x))'

Для y = ln x:

y(n) = (−1)n−1(n−1)! xn

2. Параметрически заданная функция

Если x = x(t), y = y(t):

y'x = y't x't
y''xx = (y'x)'t x't
Важно: вторую производную нельзя находить простым повторным делением y't на x't. Сначала дифференцируется уже полученная первая производная по параметру t.

3. Неявная функция

Если задано уравнение F(x, y) = 0, то при дифференцировании y считается функцией от x.

Например:

(y²)' = 2y · y'

На занятии разбиралась задача:

xy² + y + x² = 3,   x = 1,   y = 1

Получили:

y' = − 2x + y² 2xy + 1
y'(1) = −1,    y''(1) = 0

4. Дифференциалы

Дифференциал первого порядка:

dy = y'(x) dx

Дифференциал второго порядка:

d²y = y''(x)(dx)²

Дифференциал n-го порядка:

dny = y(n)(x)(dx)n

5. Приближённые вычисления

При малом приращении аргумента:

Δy ≈ dy = y'(x₀)Δx

Приближённое значение функции:

f(x) ≈ f(x₀) + f'(x₀)(x − x₀)

Абсолютная погрешность:

Δабс = |Δy − dy|

Относительная погрешность:

δ = Δабс |Δy| · 100%
Преподаватель подчеркнула: чем меньше Δx, тем точнее приближение через дифференциал.

6. Формулы Тейлора и Маклорена

Формула Тейлора:

f(x) ≈ Σk=0n f(k)(x₀) k! (x − x₀)k

Формула Маклорена — частный случай при x₀ = 0:

f(x) ≈ Σk=0n f(k)(0) k! xk

Основные разложения

ex = 1 + x + x² 2! + x³ 3! + ⋯
ln(1 + x) = x − x² 2 + x³ 3 − ⋯,   |x| < 1
(1 + x)α = 1 + αx + α(α − 1) 2! x² + ⋯
Для разложения ln(1 + x) преподаватель отдельно обращала внимание на условие |x| < 1.

Что запомнить для контрольной №2

  1. Уметь находить вторую и последующие производные.
  2. Дифференцировать неявные и параметрические функции.
  3. Вычислять дифференциалы и погрешности приближений.
  4. Применять формулы Тейлора и Маклорена.
  5. Оформлять решения с промежуточными действиями и пояснениями.
