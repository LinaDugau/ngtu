Важный нюанс контрольной

Будут задания, где нужно выбрать из предложенных интервалов те, на которых функция возрастает или убывает.

Преподаватель отдельно объяснила:

  • Предложенный интервал не обязан полностью совпадать с найденным промежутком монотонности.
  • Достаточно, чтобы он целиком находился внутри нужного промежутка.
  • Если внутри предложенного интервала функция сначала возрастает, а затем убывает, выбирать его нельзя.
  • В задании может быть несколько правильных ответов.
Например: если функция возрастает на (−3; 0), то предложенный промежуток (−2; −1) подходит.

2. Формулы, которые нужны

Теорема Ферма — экстремумы

Если x₀ — точка локального экстремума и функция дифференцируема в этой точке, то:

f'(x₀) = 0

Но обратное неверно: не каждая точка с нулевой производной является экстремумом.

Теорема Ролля

Если функция непрерывна на [a; b], дифференцируема на (a; b) и f(a) = f(b), то существует c ∈ (a; b):

f'(c) = 0

Теорема Лагранжа

f(b) − f(a) = f'(c)(b − a)

где c ∈ (a; b).

Эквивалентная запись:

f'(c) = f(b) − f(a) b − a
Нюанс: преподаватель объясняла, что теорема Лагранжа позволяет точно выразить приращение функции через производную в некоторой промежуточной точке.

Правило Лопиталя

Для неопределённостей:

0 0 ,    ∞ ∞

используется:

limx→a f(x) g(x) = limx→a f'(x) g'(x)

Преподаватель особо подчеркнула:

  • Перед применением обязательно проверить наличие неопределённости.
  • Дифференцировать отдельно числитель и знаменатель.
  • Правило можно применять несколько раз подряд.
  • Если предел отношения производных не существует, это ещё не означает, что исходный предел не существует.
  • Для неопределённостей ∞ − ∞, 0 · ∞, 0⁰, ∞⁰, 1^∞ сначала нужно выполнить преобразование.

Монотонность функции

f'(x) > 0 ⇒ f(x) возрастает
f'(x) < 0 ⇒ f(x) убывает

Локальные экстремумы

Изменение знака f'(x) Результат
+ → − Локальный максимум
− → + Локальный минимум
+ → + или − → − Экстремума нет

Критические точки: производная равна нулю либо не существует, при этом сама функция в точке определена.

Стационарные точки: f'(x) = 0.

Выпуклость графика

По терминологии преподавателя:

f''(x) > 0 ⇒ выпуклость вниз
f''(x) < 0 ⇒ выпуклость вверх

Точка перегиба — точка, в которой график меняет направление выпуклости.

Важно: равенства f''(x) = 0 недостаточно. Необходимо проверить изменение знака второй производной.

Формула Тейлора

Формула Тейлора, использованная на занятии:

f(x + Δx) = f(x) + f'(x)Δx + f''(c) 2 (Δx)²

где c находится между x и x + Δx.

Эту формулу преподаватель использовала для объяснения связи второй производной с выпуклостью графика.

3. Как решать задания на исследование функции

  1. Найти область определения функции.
  2. Вычислить первую производную f'(x).
  3. Решить f'(x) = 0 и найти точки, где производная не существует.
  4. Отметить критические точки на числовой прямой.
  5. Определить знаки первой производной на промежутках.
  6. Установить интервалы возрастания, убывания, максимумы и минимумы.
  7. Вычислить вторую производную f''(x).
  8. Найти точки, где f''(x) = 0 или не существует.
  9. Определить знаки второй производной, интервалы выпуклости и точки перегиба.
Нюанс преподавателя: если множитель производной имеет чётную степень, знак при переходе через его ноль может не измениться. Нельзя автоматически чередовать плюсы и минусы.

5. Главное к контрольной и экзамену

Особое внимание уделить:

  • Правилу Лопиталя и распознаванию неопределённостей.
  • Поиску критических и стационарных точек.
  • Определению знаков первой и второй производных.
  • Промежуткам монотонности.
  • Локальным экстремумам.
  • Выпуклости и точкам перегиба.
  • Правильному выбору предложенных интервалов в тестовых заданиях.
Итог: закончить второй модуль, отправить контрольную и обязательно потренироваться исследовать функции по первой и второй производным. Точная дата сдачи в записи не прозвучала.
