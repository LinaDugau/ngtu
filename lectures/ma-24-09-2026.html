3. Формулы и определения, которые нужно знать

Функция и её свойства

Функция в явном виде:

y = f(x)

D(f) — область определения, E(f) — множество значений.

Возрастающая функция:

x₁ < x₂ ⇒ f(x₁) < f(x₂)

Убывающая функция:

x₁ < x₂ ⇒ f(x₁) > f(x₂)

Ограниченная функция:

|f(x)| ≤ M

для некоторого M > 0 и всех x из рассматриваемой области.

Периодическая функция:

f(x + T) = f(x)

T > 0 — период. Преподаватель подчеркнула, что в заданиях нужно указывать основной (наименьший положительный) период, а не любое его кратное.

Чётная функция:

f(−x) = f(x)

График симметричен относительно оси Oy.

Нечётная функция:

f(−x) = −f(x)

График симметричен относительно начала координат.

Обратная функция

Если функция строго монотонна на выбранном промежутке, можно определить обратную функцию:

y = f−1(x)

Основные соотношения:

f(f−1(x)) = x
f−1(f(x)) = x

Графики прямой и обратной функций симметричны относительно прямой:

y = x
Примеры:
y = x², x ≥ 0 ⟷ y = √x
y = ax ⟷ y = loga x

Основные элементарные функции

Функция Что необходимо помнить
y = xα Степенная функция; область определения зависит от показателя
y = ax a > 0, a ≠ 1; проходит через (0; 1)
y = loga x x > 0, a > 0, a ≠ 1
y = sin x Значения от −1 до 1, период 2π
y = cos x Значения от −1 до 1, период 2π
y = tan x x ≠ π/2 + πk, период π
y = cot x x ≠ πk, период π

Здесь k ∈ ℤ.

Для обратных тригонометрических функций:

arcsin x ∈ [−π/2; π/2]
arccos x ∈ [0; π]
arctan x ∈ (−π/2; π/2)
arccot x ∈ (0; π)

4. Преобразования графиков — важная часть занятия

Преподаватель подробно разобрала сдвиги, растяжения, сжатия и отражения графиков.

Формула Преобразование
y = f(x − a) Сдвиг вправо на a
y = f(x + a) Сдвиг влево на a
y = f(x) + a Сдвиг вверх на a
y = f(x) − a Сдвиг вниз на a
y = f(kx), k > 1 Сжатие по горизонтали в k раз
y = f(x/k), k > 1 Растяжение по горизонтали в k раз
y = k·f(x), k > 1 Растяжение по вертикали в k раз
y = f(−x) Отражение относительно Oy
y = −f(x) Отражение относительно Ox
Нюанс: преподаватель подчеркнула, что изменение аргумента влияет на горизонтальное расположение графика, а изменение значения функции — на вертикальное.

На занятии разбирался пример вида:

y = −3 sin(4x − π/6)

Последовательность преобразований:

  1. Сжать синусоиду по горизонтали в 4 раза.
  2. Сместить вправо на π/24, поскольку 4x − π/6 = 4(x − π/24).
  3. Увеличить амплитуду в 3 раза.
  4. Отразить относительно оси Ox.

Итоговая амплитуда — 3, период — π/2.

5. Неявное задание функции

Преподаватель объяснила, что не каждую кривую можно сразу представить в виде y = f(x).

Неявная запись:

F(x, y) = 0

Пример — окружность:

x² + y² = R²

Из неё получаются две ветви:

y = √(R² − x²)
y = −√(R² − x²)

Формула окружности с произвольным центром, которую преподаватель отдельно напомнила в конце занятия:

(x − x₀)² + (y − y₀)² = R²

Здесь (x₀, y₀) — центр, R — радиус.

6. Параметрическое задание функции

Вместо выражения y через x обе координаты задаются через параметр t:

x = x(t)
y = y(t)

Преподаватель объяснила, что параметр t удобно воспринимать как время, а x(t) и y(t) — как координаты движущейся точки.

Пример — циклоида

x = t − sin t
y = 1 − cos t

Эта кривая описывает движение точки на ободе катящегося колеса единичного радиуса.

Как строить параметрическую кривую по словам преподавателя:
  1. Найти допустимые значения параметра t.
  2. Определить нули функций x(t) и y(t).
  3. Найти значения t, при которых меняется монотонность координат.
  4. Составить таблицу значений t, x, y.
  5. Отметить точки на плоскости и соединить их в правильном порядке.

Особенно важно отслеживать точки, где координата сначала возрастает, а затем убывает: там траектория может менять направление или образовывать петлю.

7. Полярная система координат

В полярных координатах точка задаётся двумя числами:

(ρ, φ)

ρ — расстояние от полюса, φ — угол относительно полярной оси.

Преподаватель подробно вывела формулы перехода между декартовыми и полярными координатами:

x = ρ cos φ
y = ρ sin φ

Обратные соотношения:

ρ = √(x² + y²)
tan φ = yx, при x ≠ 0
Нюанс: одного тангенса недостаточно для однозначного определения угла — необходимо учитывать четверть, в которой находится точка.

Пример № 1. Спираль Архимеда

ρ = φ, φ ≥ 0

Преподаватель показала, как построить её по таблице значений угла и радиуса.

Пример № 2. Лемниската Бернулли

Исходное уравнение:

(x² + y²)² = 4(x² − y²)

После перехода к полярным координатам:

ρ⁴ = 4ρ² cos 2φ

Для ненулевого радиуса:

ρ² = 4 cos 2φ
ρ = 2√(cos 2φ)

при условии: cos 2φ ≥ 0

Преподаватель показала, что график состоит из двух лепестков и напоминает знак бесконечности.
