3. Формулы, которые нужно знать

Предел функции

limx→x₀ f(x) = A

Определение предела по Коши:

∀ε > 0 ∃δ > 0: 0 < |x − x₀| < δ ⇒ |f(x) − A| < ε

Преподаватель объяснила: если x приближается к x₀, то значения функции приближаются к числу A. При этом функция необязательно должна быть определена в самой точке x₀.

Если предел конечен, функцию можно представить так:

f(x) = A + α(x), где α(x) → 0

Здесь α(x) — бесконечно малая функция.

Односторонние пределы

Предел слева:

limx→x₀−0 f(x) = A−

Предел справа:

limx→x₀+0 f(x) = A+
Главное условие существования конечного предела:
A− = A+ = A

Если односторонние пределы различаются, конечного двустороннего предела нет.

Нюанс: преподаватель отдельно разобрала ситуации, когда односторонние пределы бесконечны или один из них конечен. Нужно различать запись бесконечного предела и случай, когда предел вообще не существует.

Раскрытие неопределённостей

Основные неопределённости этого занятия:

00,      ∞∞,      ∞ − ∞

Способы раскрытия:

  • Разложение многочленов на множители.
  • Сокращение общего множителя (x − x₀).
  • Домножение на сопряжённое выражение при наличии корней.
  • Выделение старшего слагаемого при x → ∞.
  • Замена эквивалентными функциями.

Для разности корней полезна формула:

(√a − √b)(√a + √b) = a − b

Эквивалентные функции

f(x) ~ g(x) ⇔ limx→x₀ f(x)g(x) = 1

Для многочлена при x → +∞:

a₀xn + a₁xn−1 + … + an ~ a₀xn
Самое важное предупреждение преподавателя: нельзя бездумно заменять эквивалентными выражения в разности, если старшие слагаемые сокращаются.
Например:
limx→∞ (x + 5)³ − x³(x + 2)²

Нельзя заменить (x + 5)³ на x³ и получить ноль. Нужно раскрыть скобки:

= limx→∞ 15x² + 75x + 125(x + 2)² = 15

4. Примеры из занятия и контрольной работы

Пример № 1. Разложение многочленов

limx→1 2x² − x − 1x³ + 2x² − x − 2

При подстановке получается 0/0. Разложим:

= limx→1 (x − 1)(2x + 1)(x − 1)(x² + 3x + 2)
= 2 + 11 + 3 + 2 = 12

Пример № 2. Домножение на сопряжённое

limx→4 x² − 3x − 4√(5 − x) − 1
= limx→4 (x − 4)(x + 1)(√(5 − x) + 1)(5 − x) − 1
= limx→4 (x − 4)(x + 1)(√(5 − x) + 1)4 − x
= −10

Пример № 3. Использование таблицы эквивалентных

limx→0 ln(1 + arcsin 3x)∛(1 + arctan x) − 1

Применяем эквивалентности:

arcsin 3x ~ 3x, arctan x ~ x
ln(1 + arcsin 3x) ~ 3x
∛(1 + arctan x) − 1 ~ x3

Следовательно:

= limx→0 3xx/3 = 9

Преподаватель назвала это примером хорошего, короткого решения.

Пример № 4. Экспоненты

limx→0 x²(ex − e−x)ex³+1 − e

Выносим множители:

= limx→0 x² e−x(e2x − 1)e(ex³ − 1)

Используем:

e2x − 1 ~ 2x, ex³ − 1 ~ x³, e−x → 1
= limx→0 2x³e · x³ = 2e
Преподаватель уточнила, что примеры, разобранные в конце занятия, взяты из вашей контрольной работы.

  • Бесконечность в ответах вводится русской буквой б; преподаватель сказала, что большая Б тоже принимается.
  • Если важен знак, вводить +б или -б без пробелов.
  • Преподаватель планировала добавить также латинский вариант inf, но на момент занятия это было только намерение.
  • В заданиях на восстановление определения Коши фразы необходимо перетаскивать в правильном порядке сверху вниз.
  • Если учебник на платформе «Лань» не открывается, можно попробовать вход через учётную запись НГТУ. Преподаватель признала проблему с доступом и собиралась искать другую ссылку.
  • Вопросы можно задавать в MAX и в комментариях к заданиям.
